About this build
This is the design prototype. Its data layer is shaped exactly like the production schema — the same tables, columns and relationships — and every mutation goes through a single service call, so swapping the in-memory store for the Neon client is a one-file change. Nothing here is persisted to browser storage as a source of truth. The schema, RLS policies and API contract ship alongside this file.
